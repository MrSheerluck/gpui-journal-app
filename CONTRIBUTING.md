# Contributing to Dainiki

Thank you for your interest in contributing to Dainiki.

We currently **do not accept pull requests or external code contributions**. All development and maintenance are handled internally by the maintainers.

However, we welcome bug reports, feature requests, and suggestions through [GitHub Issues](../../issues).

Feel free to open an issue to report a problem or propose an improvement. We'll review it and handle any necessary changes ourselves.

Thank you for helping us improve Dainiki.
