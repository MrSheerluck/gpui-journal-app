Dainiki is a free, open-source, local-first journaling application built with Rust and GPUI for macOS, Windows, and Linux.

Capture your everyday life through text, images, videos, and audio in a continuous, vertically scrolling daily timeline.


## Features

Local-first: Your journals stay on your device and work offline.

Daily timeline: Write and revisit memories through a continuous scrolling experience.

Multimedia journaling: Capture memories using text, images, videos, and audio.

Private by design: No account required for local journaling.

Optional cloud sync: Synchronize your journals across devices with SMBL Cloud.

Tech Stack

- Rust
- GPUI
- GPUI Kit

## Status

🚧 Under active development. Features listed above are planned and may not yet be available.

Built with care by SMBL.


## Contributing to Dainiki

Thank you for your interest in contributing to Dainiki.

We currently **do not accept pull requests or external code contributions**. All development and maintenance are handled internally by the maintainers.

However, we welcome bug reports, feature requests, and suggestions through [GitHub Issues](../../issues).

Feel free to open an issue to report a problem or propose an improvement. We'll review it and handle any necessary changes ourselves.

Thank you for helping us improve Dainiki.
